# Workspace

The Workspace is where you write down how your business runs: procedures, checklists, price lists, decisions and notes. Your agents read these pages before they start work, follow them, and suggest changes for you to accept. Think of it as your company handbook, written once and used by every agent that needs it.

## What you'll see

- **The page list on the left.** It starts with **Workspace** (the home screen) and a **+ Page** button. Your pages sit underneath as a tree: a page can hold other pages inside it. Click the small arrow next to a page to show or hide the pages inside it, and the **+** at the end of a row to add a page inside that one.
- **Small marks on a page's row.** A number means agents have suggested that many changes to it. A lock (🔒) means the page is private.
- **Deleted (number)** at the bottom of the list, when you have deleted pages. Open it to **Restore** any of them.
- **The home screen.** A search box (**Search every page**), then **Waiting for you** (changes agents have suggested), **Recently changed** pages, and **Start from a template**.
- **An open page.** The path to the page at the top, its icon and title, who last edited it and when, then a small toolbar and the page itself. On the right is a settings panel: **Who can see it**, **When agents want to change it**, **Protected**, **Give this page to an agent**, **Used by**, and the **History** and **Delete** buttons.

## Key ideas

**Pages save as you type.** The word next to the toolbar tells you where things stand: **Editing…**, **Saving…**, **Saved**, or **Not saved** if something went wrong.

**Agents read the pages that fit their task.** When an agent starts work, it is told which of your pages best match the task. It can then search the workspace and read any page it is allowed to see. Agents are told to follow a page's procedure when there is one, and to say in their report which pages they used.

**Who can see a page.** Each page is set to one of:

- **Every agent**.
- **Only some groups or agents**: only the agents in the groups (departments) you tick, and any agents you tick by name, such as one position from another group.
- **Private: no agent sees it**. No agent can find, list or read it, and it is never sent to any AI model. Only you see it, in this app.
- **Same as** the page above it. This is the starting setting for a page inside another page, so a whole section follows one choice. A page at the top starts as **Every agent (the default)**.

The general Talqava assistant you chat with, which works for you directly, may read every page that is not private.

**Agents suggest; you decide.** When an agent wants to change a page, it sends you a suggestion. You see exactly what it would add (+) and remove (−), with its note on why. Nothing changes until you press **Accept**. If you trust agents with a page, you can set it to **They may change it directly**.

**Protected pages.** Tick **Protected: agents never change it directly** for pages that must never change without you, such as prices, legal terms and people policies. Agents can still suggest changes to a protected page.

**History.** Every version of a page is kept, up to the last 100. Your own typing within a couple of minutes counts as one version. You can look at any version and put it back.

**Tables hold records.** A page can carry tables under its text: a customer list, a stock count, a tracker. Each column holds one kind of value: **Text**, **Number**, **Date**, **Choice** (pick one from a list you set) or **Person** (you, or a position on your chart). A table follows its page: agents who can see the page can read the table, and an agent's change to a row waits for you, exactly like a change to the page, unless the page is set to take agents' changes straight away. On a protected page it always waits.

**Agents can add pages too.** An agent can save its result as a new page, but only inside a page it is allowed to see. A new page made this way follows that page's **Who can see it** setting. You can also save a finished task's report as a page yourself (see below).

## Which one should I use?

Talqava has four places to keep knowledge. Each is for a different job.

| Use | For | Example | How agents use it |
|---|---|---|---|
| **Workspace** | How you do things, written by you | "How we handle a refund", a weekly checklist, your prices | They follow it, and suggest improvements |
| **Library** | Files you already have | Contracts, PDFs, spreadsheets, brochures | They search inside them for the passages they need |
| **Memory** | Short facts worth remembering | "Our fiscal year starts in April" | Relevant facts are put in front of them automatically |
| **Skills** | Steps an agent worked out and saved | "How to prepare the monthly sales summary" | They read the skill before a task it covers |

A simple rule: if you would write it yourself and want it followed, make it a page. If it is a file, put it in the Library. If it fits in one sentence, put it in Memory.

## How to…

### Add a page

1. Press **+ Page** at the top of the list (or **+ New page** on the home screen).
2. Type a title and press Enter.
3. Start writing. To put the page inside another one, press the **+** on that page's row instead.

### Format a page

1. Type **/** at the start of a line to open the block menu.
2. Pick **Text**, **Heading 1**, **Heading 2**, **Heading 3**, **Bulleted list**, **Numbered list**, **Checklist**, **Table**, **Quote**, **Code** or **Divider**. Type a word after the / to narrow the list, use the arrow keys, and press Enter.
3. For bold, italic, strike-through, code or a link, select some text and use the toolbar buttons.

### Change a page's icon

1. Click the icon next to the title.
2. Pick one, or type a word to find it (money, legal, team…). The arrow keys and Enter work too. You can also type any emoji and press Enter, or choose **No icon**.

### Link one page to another

1. In a page, type **[[** and the start of the other page's name.
2. Pick the page from the list (the arrow keys and Enter work too). A link to it appears.
3. Click a link to open that page. The link keeps working if the page is renamed, and shows its new name.
4. Each page lists the pages that link to it under **Linked from**. Agents can write **[[Page name]]** too, and it becomes a link.

### Start from a template

1. Go to the **Workspace** home screen.
2. Under **Start from a template**, choose **Operations handbook**, **Sales playbook**, **People handbook**, **SOP library** or **Price list**, and press **Add these pages**. The same packs are in the **Marketplace** under **Page packs**, where **Preview and add** shows exactly what will be added and **Undo** takes it back.
3. The pages appear under a new page named after the template. If your chart has a matching group (Operations, Sales or People), only that group can see them. The **Prices** and **Time off** pages start as Protected.
4. Edit the pages to match how you really work.

### Choose who can see a page

1. Open the page.
2. Under **Who can see it**, pick an option.
3. For **Only some groups or agents**, tick the groups and the agents, and press **Save**.

### Accept or decline an agent's suggestion

1. Open the page from **Waiting for you** on the home screen, or from a page with a number beside it.
2. Read the change: lines with + would be added, lines with − removed.
3. Press **Accept** or **Decline**. **See the task** shows the work that led to it.

### Give a page to an agent

1. Open the page.
2. Under **Give this page to an agent**, pick the agent.
3. Say what to do with it, for example "Follow this procedure for this week's orders". Leave it empty and the agent is simply asked to follow the page.
4. Press **Give the task**.

### Keep a table of records on a page

1. Open a page and scroll below its text. Press **+ Add a table**. It starts with a few example columns.
2. Press **Columns** to name the columns, choose each one's type and, for a **Choice** column, type its choices separated by commas. Press **Save columns**.
3. Press **+ Add a row**, then type straight into the cells. Each change saves as you leave the cell. A value that does not fit its column (letters in a **Number** column, say) is refused with a message.
4. To delete a row, press **×** at its end. To delete the whole table, press **Delete**; export it first if you may need it.

When an agent asks to add or change a row, it appears on the table under **Waiting for you** and in your **Inbox**. Press **Accept** or **Decline**.

### Bring in or take out a table as a CSV file

1. To make a new table from a file, press **Import a CSV as a new table** under the page's text and pick the file. The first line becomes the column names, and each column's type is worked out from its values.
2. To add rows to a table you already have, press **Import CSV** on that table. Columns are matched by name; columns the table does not have are ignored. If a value does not fit its column, nothing is imported and the message says which line.
3. To take a table out, press **Export CSV**. It opens in any spreadsheet.

### Save a task's report as a page

1. Open a finished task.
2. Under **Workspace**, press **Save the report as a page**.
3. Give it a title, choose where to put it, and press **Save as a page**.

### Move, find and restore pages

1. To move a page, drag it onto another page to put it inside. Drag it onto the **Workspace** line at the top to bring it back to the top level.
2. To find something, type in **Search every page** on the home screen.
3. To see older versions, open the page and press **History**. Click a version to read it; press **Put back** to restore it. The current text stays in the history.
4. To delete, press **Delete**. Pages inside it are deleted too. Bring them back from **Deleted** at the bottom of the list within 30 days; after that they are removed for good. **Empty deleted** removes them all now, after asking.

## Tips

- Write procedures as numbered steps. Agents follow clear steps best.
- Use **Protected** for anything with money, legal or people consequences.
- Keep private notes in the workspace with **Private: no agent sees it**. They stay on this computer and never reach any agent.
- **Used by** on a page shows which tasks read it, suggested a change, or changed it. It is a quick way to see whether a page is being used.

## If something goes wrong

- **"This page changed while you were editing it."** The page was changed somewhere else while you typed. Press **Reload**. Your text is still in the editor until you do, so copy anything you need first.
- **"The page changed in the same places since the agent read it."** You and the agent changed the same lines. The app asks whether to use the agent's version. Choose OK to use it (your newer text stays in **History**), or Cancel to keep yours.
- **"… takes a number / a date / one of …"** A value did not fit its column in a table. Type a value of that kind, or change the column's type under **Columns**.
- **"Line 3: … Nothing was imported."** One value in the CSV file does not fit its column. Fix that line in the file, or change the column's type, and import again.
- **"That page is too long."** Split it into several pages inside one parent page.
- **"A page cannot go inside itself."** You tried to drop a page into one of its own sub-pages. Drop it somewhere else.
- **"There is no such page, or it is not one you may see."** The page was deleted. Look under **Deleted**.
