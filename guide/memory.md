# Memory

Memory is where Talqava keeps short facts worth remembering between chats and tasks, such as "I write mystery novels under a pen name" or "our fiscal year starts in April". The Talqava assistant, and any agent with the **Memory** power, adds to it on its own and tells you when it does; you can add, edit, move and forget entries here. It saves you repeating the same background every time you ask for something.

## What you'll see

Memory is one of the two parts of **Knowledge**, under **Team**. The switch at the top goes between **Memory** and **Skills**.

- **Tabs along the top.** **General**, then one tab per project, each with a count of its entries. **＋ New project** adds one.
- **A short note** saying where this memory is used. Inside a project you also get **Rename** and **Delete project**.
- **A box to add something**, with a **Remember this** button (or **Remember this in** the project's name).
- **Your entries**, newest first, each with when it was saved and edited, and the buttons **Edit**, **Move to…** (when you have projects) and **Forget**.
- **A search box** (**Find in … memory**) once a tab holds eight or more entries.

## Key ideas

**General memory goes everywhere.** Entries under **General** go into every chat, in every project. Your agents also get them when they work on tasks.

**Projects keep things apart.** A project is the folder for one client or piece of work; it also holds that work's tasks and chats (see [Projects](projects.md)). Its memory goes only into that project's chats, together with General memory. What the agent learns in a project's chat stays in that project.

**Memory is for facts, not documents.** Each entry is short (up to 1,500 characters). When there is more memory than fits comfortably, Talqava picks the entries that match what you are talking about, plus the newest ones. The rest are still kept.

**You see it when something is remembered.** In a chat you'll see a small note such as **Remembering…**, **Updating memory…** or **Forgetting…**, with buttons to change or remove what was saved.

**Your organization has its own memory too.** On the **Organization** page, the **Memory** view holds notes for the **Whole organization** and for each group. Each agent sees the organization's notes, its own group's, and its own. Agents also keep a short record of the work they finished there, marked **Recorded automatically**. Only the notes that bear on the task in hand are sent to the AI model.

**Memory is not private.** Whatever is in memory can be sent to the AI model along with a chat or task. Keep passwords, card numbers and anything secret out of it. For confidential files, use the Library and mark them **Private**.

## How to…

### Add something to remember

1. Pick **General**, or the project it belongs to.
2. Type the fact in the box, in one or two sentences.
3. Press **Remember this**.

You can also just say it in a chat: "Remember that our office is closed on Fridays."

### Change or remove an entry

1. Find the entry. Use the search box if the list is long.
2. Press **Edit**, change the text, and press **Save**. Or press **Forget** to remove it.

### Start a project

1. Press **＋ New project**.
2. Type a name, such as a client's name, and press **Add project**.
3. Add facts under the new tab. Chats in that project will use them.

### Move an entry to another project

1. Open the **Move to…** menu on the entry.
2. Pick **General** or another project.

### Rename or delete a project

1. Open the project's tab.
2. Press **Rename**, type the new name and press **Save name**. Or press **Delete project** and confirm.

Deleting a project deletes its memories for good. Its chats move to General, and its tasks stay without a project.

### Add something every agent in the organization should know

1. Go to **Organization** and open the **Memory** view.
2. Type the note, and choose **Whole organization** or one group.
3. Press **Remember this**.

**Where it is kept.** Your organization's shared memory is in the organization's own database on this computer, beside its Library and Workspace, and is searched the same way. Notes from before this change were moved over automatically; nothing was lost.

## Tips

- One fact per entry. Short entries are easier to find, match and correct.
- Read through memory now and then, and **Forget** anything that is out of date.
- Use a project for each big client, so details from one never slip into another's chats.
- Long procedures belong on a Workspace page; files belong in the Library.

## If something goes wrong

- **"That is too long for one memory (1500 characters at most)."** Split it into a few short entries, or put it on a Workspace page.
- **"Nothing to remember."** The box was empty. Type something first.
- **"A project needs a name of up to 40 characters."** Use a shorter name.
- **"There is already a project called …"** Pick a different name.
- **"General is already there."** General can't be used as a project name.
- **An agent remembered something wrong.** Press **Edit** or **Forget** on the entry, here or on the note in the chat.
