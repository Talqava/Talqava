# Skills

A skill is a written-down procedure: the steps for a job that comes up again and again, such as preparing the monthly sales summary. When an agent works out how to do something well, it can save the steps as a skill so the job is done the same way next time. The Skills page lists every saved skill, so you can read them and remove ones you no longer want.

## What you'll see

- **A list of skills.** Each line shows the skill's short name and a one-line description of what it is for.
- **The full steps.** Click a skill to open it and read exactly what was saved.
- **A Delete button** inside each open skill.
- If there are none yet: **No skills yet.** with a hint to ask the agent to "save that as a skill".

## Key ideas

**Skills are written by agents, not typed in here.** You create one by asking in a chat, after a task went well: "Save that as a skill." The Talqava assistant, and any agent with the **Skills** power, can save new skills. This page is for reading and deleting them.

**Every agent can follow them.** Saved skills are shared across your whole team. Agents without the Skills power can still read a skill and follow it; they just can't write new ones. Agents are told to read the skill that covers their task before they start.

**Saving again replaces.** A skill is known by its name. If an agent saves a skill with a name that already exists, the new steps replace the old ones.

**How skills differ from Workspace pages.** A Workspace page is written by you: your rules and procedures, which agents follow and can only suggest changes to. A skill is written by an agent: how-to notes from its own experience. If a procedure matters to the business, or needs your approval to change, put it on a Workspace page.

## How to…

### Save a new skill

1. Ask an agent to do the job in a chat, and help it until the result is right.
2. Then say: "Save that as a skill", and add a name if you like, for example "monthly sales summary".
3. Open **Skills** to check the steps it saved.

### Use a skill

1. Ask for the job as usual, for example "Do the monthly sales summary".
2. The agent reads the matching skill and follows it. You can also name the skill to be sure: "Use the monthly sales summary skill."

### Change a skill

1. Ask the agent in a chat to update it, for example "Update the monthly sales summary skill: add last year's figures for comparison."
2. It saves the new steps under the same name, replacing the old ones.

### Delete a skill

1. Open **Skills** and click the skill.
2. Press **Delete** and confirm.

## Tips

- Save skills for jobs you'll want again, not one-offs.
- Read a new skill after it is saved. If a step is wrong, ask the agent to fix it straight away.
- Keep one skill per job. Several small, clear skills work better than one long one.
- If a skill turns into company policy, copy it onto a Workspace page and protect it there.

## If something goes wrong

- **"No skill named …"** An agent looked for a skill that doesn't exist, perhaps under a slightly different name. Check the exact name on the Skills page and use that.
- **"A skill needs a name."** The agent tried to save a skill without a name. Ask it again and give the skill a name.
- **An agent ignored a skill.** Name the skill in your request, so the agent reads it first.
- **The page is empty although you asked for a skill.** The agent may not have been able to save one. Ask the Talqava assistant in Chat, which can always save skills.
